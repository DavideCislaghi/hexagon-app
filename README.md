# Hexagon App

Personal gym app built with HTML/CSS/JS.

## Structure

```
hexagon-app/
├── app/          — versioned HTML app files (Hexagon_v{N}.html)
├── exercises/    — exercise photos organised by muscle group
│   ├── back/
│   │   └── barbell-row/
│   │       ├── start.jpg
│   │       └── end.jpg
│   ├── chest/
│   ├── legs/
│   ├── shoulders/
│   ├── arms/
│   ├── core/
│   └── glutes/
└── tools/        — utility tools (ExerciseBuilder, etc.)
```

## Image URLs

Raw image URLs follow this pattern:
`https://raw.githubusercontent.com/DavideCislaghi/hexagon-app/main/exercises/{muscle-group}/{exercise-name}/start.jpg`
