Sort Controls

Three concepts — Hexagon design system · Tracks page

Option A — Pill Row Familiar

Scrollable row of pills above the track list. One active at a time; tapping toggles direction on the same key (second tap reverses). Same pattern as rest timer pills.

✓ StrengthsAll options visible at once. Matches existing app patterns. Minimal learning curve.
✗ Trade-offsCan get crowded if adding more sort keys. Direction (asc/desc) requires second tap — not self-evident.
Option B — Sort Bar Compact

Single row that reads "SORT · Title ↑". Tapping cycles through all options. Very space-efficient — works even if you add 10 sort options.

✓ StrengthsTiny footprint. Scales to many options. Clean, minimal look.

Option C — Segmented Control Recommended

4-segment bar: NAME · BPM · DURATION · VIBE. Tap once to sort asc, tap again to flip to desc. Bottom accent bar marks the active segment. Direction arrow flips in-place.
